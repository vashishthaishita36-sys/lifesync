# LIFESYNC: AI-Powered Personal Digital Twin

LIFESYNC is a Flask web app that logs daily habits, learns how they affect
productivity, predicts productivity, simulates "what if" changes, and
recommends improvements.

## Features
- Daily entry form with input validation (sleep, bedtime, study, exercise,
  screen time, tasks, spending, productivity score)
- Digital twin dashboard: 7-day rolling averages, streak, predicted
  productivity, 30-day trend chart
- Machine learning: Linear Regression and Random Forest compared on MAE and
  R-squared; the better model is saved
- What-if simulator with sliders
- Recommendations: top 3 habit changes ranked by predicted gain
- Retrain button, so the twin updates as new entries are added
- Light and dark theme

## Tech stack
Python, Flask, SQLite, pandas, NumPy, scikit-learn, joblib,
HTML/CSS/JavaScript, Chart.js

## Setup (Windows)
```
git clone https://github.com/vashishthaishita36-sys/lifesync.git
cd lifesync
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
python setup_demo.py
python app.py
```
Then open http://127.0.0.1:5000 in a browser.

`setup_demo.py` generates the starter data, loads it into the SQLite
database, and trains the model.

## About the data
The first 90 days are a **synthetic starter dataset** generated by
`generate_data.py`, used to build and test the pipeline. Entries added
through the form are real data and are stored in the same table. Pressing
"Retrain" updates the model with all entries.

## Project structure
```
app.py            Flask routes and validation
database.py       SQLite functions
ml.py             Training, prediction, recommendations
dsa_utils.py      Sliding-window rolling average and streak
generate_data.py  Synthetic starter data
seed_db.py        Loads starter data into the database
setup_demo.py     Runs the three setup steps
templates/        HTML pages
static/           CSS
```
